
A secure upload portal.

Ki is a simple secure upload portal.
It's main purpose is to share sensitive files with third parties.

## Features

- [x] File upload / download
- [x] File checksums (SHA512, SHA256, SHA1, MD5)
- [x] File expirey after number of downloads / time limit
- [x] No file size limit
- [x] Password protected downloads
- [x] Server-side encryption
- [x] No Javascript (Until E2E encryption is added)
- [x] CloudFlare MitM warning (users are warned if the server detects a CloudFlare proxy)
- [ ] E2E encryption (currently provides bash commands on the upload / download page for doing this)
- [ ] SSL without a reverse proxy
